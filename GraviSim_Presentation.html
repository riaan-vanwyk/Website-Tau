GraviSim: 2D Orbital Gravity Simulator

GraviSim: 2D Orbital Gravity Simulator is an interactive, real-time physics simulation built in Python using Ursina (+ custom CPU-based per-pixel renderer) and Tkinter. The application models dynamic two-body orbital mechanics governed by gravitational force calculations and custom velocity vectors. Users can seamlessly manipulate the environment on the fly through a control panel to apply preset orbital configurations or inject custom parameters like mass, radius, position, and velocity. The visual experience is enhanced by a white trail tracking system that maps the progressive trajectory of the celestial bodies over time.  Python   Physics   Graphics   Ursina
